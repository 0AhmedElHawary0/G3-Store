## 🛒 Laravel E-Commerce Website

A modern e-commerce web application built with Laravel 🧱. This project includes product listings, shopping cart functionality 🛍️, user authentication 🔐, and an admin panel 🧑‍💻 for managing products and orders.

## ✨ Features

- 👤 User registration & login
- 🗂️ Product catalog with categories
- 🛒 Shopping cart system
- 📦 Order management
- 🧑‍💻 Admin dashboard
- 📱 Responsive UI *(Bootstrap)*
